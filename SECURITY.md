# Security policy

Please do not publish details of a suspected vulnerability before a fix or
mitigation is available. Open a private security advisory where supported, or
contact the maintainer through a verified contact channel.

This project is an early-stage security control and has not been independently
audited. Do not rely on it as the only control protecting sensitive systems.

When reporting an issue, include the affected version, Python version,
operating system, configuration shape (with secrets removed), and minimal
reproduction steps. Never include production credentials or personal data.
